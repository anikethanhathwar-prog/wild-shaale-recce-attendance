Wild Shaale — School Recce

Offline-first school visit data collection

Start in Setup while you are connected to the internet.

Setup the app

Enter the Google Apps Script Web App URL and the destination Google Sheet. Use the same destination sheet for all recce entries in this project.

The Apps Script account must have edit access to the destination spreadsheet. Setup creates configuration tabs if they are missing; it does not erase existing sheet data.

Configuration tabs in your spreadsheet

Location Master

Columns: Park Name, District Name, Taluka Name, Village Name. Add one row for each location combination you want available for suggestions.

Form Configuration

Controls additional questions. Columns: Field ID, Field Label, Type, Required, Options, Section, Active. Separate multiple options with the | character.

Educators

Optional educator list. Columns: Educator Name, Active.

Sync Log

Records the result of sync attempts.
